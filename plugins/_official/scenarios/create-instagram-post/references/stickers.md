# Стікери

Стікер ілюструє **предмет або метафору**, а не слово. Якщо фразу не
можна намалювати одним об'єктом — стікера тут не місце.

## Коли потрібен

Так:
- фраза називає річ: «файл», «чат», «збірка»
- фраза містить метафору: «порожня голова», «стіна тексту»
- фраза протиставляє: «магія проти дисципліни»

Ні:
- службові зв'язки: «тому», «а далі», «і ось»
- повтор уже показаного
- фінальна фраза — там працюють ведучий і текст
- будь-де, якщо попередній стікер зник менш ніж секунду тому

Орієнтир — **один стікер на 4–6 секунд**. Ролик на 30 секунд це
5–7 стікерів, не п'ятнадцять.

## Базовий набір

Ці повторюються майже в кожному ролику — згенеруй раз і тримай у
`assets/stickers/`:

| id | Промпт | Для чого |
|---|---|---|
| `brain-empty` | `empty human head silhouette, dotted outline, single line art` | забування, брак контексту |
| `md-file` | `markdown file icon with folded corner, thick outline` | файл контексту, документація |
| `robot-dark` | `small friendly robot in the dark, only eyes glowing` | модель без контексту |
| `broken-build` | `cracked terminal window with red X, flat vector` | зламана збірка |
| `stopwatch` | `stopwatch with lightning bolt, dynamic angle` | швидкість, дедлайн |
| `chat-bubble` | `chat bubble filled with code brackets` | промпт, діалог з ШІ |

## Стиль

Модель — `openrouter/google/gemini-2.5-flash-image`, той самий, що й для
ведучого. До кожного промпта додавай спільний хвіст:

```
Sticker illustration of a single object. Bold saturated colors, clean
cartoon style with light 3D volume, soft shading and glossy highlights,
crisp dark outlines around the shapes. ONE object only, no scene, no
props around it, no ground, no shadow cast on the background. Centered,
filling most of the frame with an even margin on all four sides.
Background: plain solid pure white, completely empty, no gradient, no
checkerboard, no grey squares, no border, no frame. No text, no letters,
no numbers, no logo, no watermark. Sharp clean edges suitable for cutout.
```

**Не проси прозорий фон.** Модель малює пікселі, тому у відповідь на
«transparent background» вона МАЛЮЄ шахматку прозорості як картинку —
те саме грабло, що й з позами ведучого. Проси рівний білий, альфу ріж
окремим кроком.

**Кант не домальовуй кодом.** Модель малює біле кільце сама, навіть коли
її про це не просиш, і робить це краще: пробували нарощувати альфу —
кільце лягало поверх намальованого, виходило подвійним, силует розпухав,
а просвіти між частинами предмета затягувало. Лишай як згенеровано.

**Кант саме БІЛИЙ, попри світле тло ролика.** Це виглядає суперечливо,
але перевірено на референсі: біле кільце товсте, а всередині насичений
малюнок, тож кільце читається як окремий предмет, що лежить поверх
кадру. Це головна деталь, яка робить набір набором — картинки всередині
можуть бути хоч від різних художників, цілісність тримає однакове
кільце й однакове місце в кадрі.

Тексту всередині стікера не має бути ніколи: він конкурує з
субтитрами і не читається на швидкості.

## Після генерації

```bash
python assets/stickers/make_stickers.py [імена.png]
```

Зрізає біле тло заливкою від країв і обрізає до контенту. Кант і тінь не
чіпає. Поруч лишається `<id>.raw.png` — копія «як згенеровано», щоб зріз
можна було переробити з іншим порогом, не витрачаючи ще одну генерацію.

Матинг-моделлю (`hyperframes remove-background`) тут не користуватись: на
позах ведучого вона приймала світлі ділянки за фон і з'їдала 41.5 %
фігури.

## Підпис-пігулка

Під стікером — маленька пігулка зі скругленням «на повну»: суцільна
заливка, білий жирний текст, одне-два слова. Картинка каже *що*,
пігулка каже *хто саме*: без неї «мозок із біцепсами» — просто мозок, а
з підписом «максимум» — уже теза. Колір довільний, але один стікер —
один сталий колір між роликами.

## Анімація

Поява — pop-in 220 мс: масштаб 0.8 → 1.06 → 1.0, прозорість 0 → 1.
Легкий перельот обов'язковий, лінійна поява виглядає мертво.

Зникнення — 150 мс до появи наступного, масштаб 1.0 → 0.94,
прозорість у нуль. Два стікери в кадрі одночасно не тримай.

Поки стікер висить — повільний дрейф на 8–12 px або нахил на 1.5°.
Абсолютно статичний елемент у кадрі читається як зависла картинка.
